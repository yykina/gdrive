rclone

A personal Google Drive mount on Ubuntu.

This OAuth application is operated by yykina for personal use. It authorizes the open-source rclone program to access the account owner's Google Drive from their own computer.

What it does

rclone makes Drive files accessible through a local folder and the Dolphin file manager. The owner can browse, download, upload, edit, rename, move, and delete files using the permissions granted during Google authorization.

This is a personal configuration of rclone. It is maintained by yykina independently of Google and the rclone project.

Why it requests Drive access

Drive access is used to list existing files and folders, read file contents, and save changes back to Drive. The application requests read and write access because it is used as a writable filesystem. The public website does not request authorization or receive Drive files.

Where data is handled

File transfers take place between the owner's computer and Google Drive. Authorization tokens and file caches are stored on the owner's computer. Details about access, storage, sharing, and revoking access are in the privacy policy.
